# 中越語音翻譯器

讓兩個人面對面共用一支 iPhone，逐句在繁體中文與越南文之間翻譯。A 側說中文、看中文；倒轉的 B 側說越南文、看越南文。每句說完才翻譯，譯文可由裝置念出。

## 開啟方式

- 在電腦上直接以瀏覽器開啟 `index.html`，即可查看介面並用鍵盤輸入測試。翻譯時需要網路。
- 在 iPhone 上，請把這些靜態檔案放到 HTTPS 網址，以 **Safari 瀏覽器分頁**開啟，允許麥克風權限。請勿加入主畫面後當作 Web App 開啟；該模式可能無法使用語音辨識。本版不含部署或 HTTPS 設定。
- 不需安裝套件、執行建置指令或填入 API 金鑰。

## 使用方式

1. A 側點「點一下說中文」，B 側點「Nhấn để nói」。按一下開始聽寫，再按一下可手動結束；停頓後也會自動結束。辨識中的文字會即時顯示。
2. 翻譯完成後，兩側顯示同一段對話：A 側看中文，B 側看越南文。若開啟自動播放，裝置會念出對方語言。每句旁的播放按鈕可再念一次。
3. 語音辨識不可用、權限被拒或辨識錯誤時，點該側鍵盤圖示，輸入文字並送出。翻譯失敗時保留原文，可按「重試」。
4. 工具列可開啟常用句、紀錄及設定。常用句需先指定由 A 或 B 發話，再點句子；可從對話加入常用句，也可刪除。設定可調整字體、兩種語言的語速、自動播放及選填電子郵件。

## 測試方式

1. 用電腦瀏覽器直接開啟 `index.html`，檢查開發者工具主控台是否有 JavaScript 錯誤。若瀏覽器沒有語音辨識，畫面應顯示提示，鍵盤輸入仍可用。
2. 網路可用時，由 A 側鍵盤輸入「你吃飽了嗎」，確認兩側顯示中文與越南文；由 B 側輸入「Em ăn cơm chưa」，確認兩側顯示越南文與中文。翻譯結果由 MyMemory 提供，請人工核對語意與字形。
3. 暫時斷網，再送出一句，確認錯誤提示、原文及「重試」出現，畫面不會一直停在翻譯中。恢復網路後再按重試。
4. 新增或刪除常用句、完成幾句對話後重新整理，檢查紀錄與常用句是否保留。清空紀錄時應先詢問確認。

## 需要 iPhone Safari 實機測試

- 使用 HTTPS 的 Safari **分頁**測試 `zh-TW` 與 `vi-VN` 聽寫、即時文字、停頓自動結束及再次點按手動結束。
- 測試麥克風權限拒絕、安靜無聲、8 秒保護計時器、網路中斷及錯誤提示的兩種語言。
- 測試譯文非同步返回後是否能自動播放、首次點按的語音解鎖、播放後再次聽寫是否能收音，以及兩種語言的聲音與語速。
- 確認畫面在不同 iPhone 尺寸、瀏海及底部橫條下完整可操作；確認 B 側從對面看時的文字與按鈕方向。
- 測試背景切換、Safari 重新載入及裝置上可用語音清單延後載入時的行為。

## 已知限制與資料處理

- 語音辨識、翻譯與部分語音播放依賴瀏覽器、裝置及網路；本版不支援離線翻譯。免費翻譯 API 有額度與單次文字長度限制。
- 越南文翻成中文時，MyMemory 可能回傳簡體字；本版不自動轉為繁體。譯文仍需由使用者核對，尤其是人名、地名與重要內容。
- 對話、常用句與設定存在目前瀏覽器的 `localStorage`；清除網站資料或使用無痕模式可能使它們消失。翻譯文字會送往 MyMemory；若設定電子郵件，翻譯請求也會附上該地址。
- 可用的中文或越南文聲音由裝置決定；缺少對應聲音時，瀏覽器會依語言代碼自行選擇，發音可能不同。iPhone 的首次播放、播放後收音及語音辨識支援情況都需要實機確認。
- **iPhone 靜音開關會讓語音播放無聲**（實機確認，2026-11-16）：iOS 把 Safari 的語音朗讀歸為提示音，側邊開關切到靜音時不會出聲，音樂與影片則不受影響。網頁無法繞過此限制；使用前請關閉靜音並調高音量。設定面板與播放錯誤訊息都已加上提示。
