# 中越語音翻譯器

讓兩個人面對面共用一支 iPhone，逐句在繁體中文與越南文之間翻譯。A 側說中文、看中文；倒轉的 B 側說越南文、看越南文。每句說完才翻譯，譯文可由裝置念出。

## 開啟方式

- 在電腦上直接以瀏覽器開啟 `index.html`，即可查看介面並用鍵盤輸入測試。翻譯時需要網路。
- 在 iPhone 上，請把這些靜態檔案放到 HTTPS 網址，以 **Safari 瀏覽器分頁**開啟，允許麥克風權限。請勿加入主畫面後當作 Web App 開啟；該模式可能無法使用語音辨識。目前已部署在 GitHub Pages：<https://jj025168-gif.github.io/zh-vi-voice-translator/>（推到 `main` 約一分鐘後自動更新）。
- 不需安裝套件或執行建置指令。不填金鑰也能用（MyMemory 免費翻譯）；填入 Claude API 金鑰後改用 AI 翻譯（見下節）。

## AI 翻譯（Claude）

- 到 <https://console.anthropic.com/> 註冊、儲值（最低 US$5），在 API Keys 建一把金鑰，貼到本頁「設定 → Claude API 金鑰」。建議同時在 Console 的 Limits 設定每月花費上限。
- 金鑰只存在該裝置瀏覽器的 `localStorage`，由 Safari 直接呼叫 `api.anthropic.com`（帶 `anthropic-dangerous-direct-browser-access` 標頭），沒有中繼伺服器。換裝置或清除網站資料需重新輸入；金鑰外洩時到 Console 撤銷即可。
- 模型可選 Opus 5.5（最準）、Sonnet 5.5（平衡）、Haiku 5.5（最省）。每句約 400–600 輸入 token、數十輸出 token；以每天 100 句估算，Opus 約每月 NT$300、Sonnet 約 NT$150、Haiku 不到 NT$10。
- 提示詞固定「A 是男生說中文、B 是女生說越南文」，並依「兩人關係」選擇越南文稱呼（情侶／夫妻用 anh／em 等）；越→中一律輸出台灣用語的繁體字。會附上最近 6 句已翻譯對話作為上下文，讓稱呼一致。「稱呼或語氣補充」可填名字或語氣要求。
- 「測試翻譯」按鈕會以「你吃飽了嗎？」實際送一次請求，顯示譯文或錯誤原因（金鑰無效、額度不足、網路、AI 拒絕）。
- 無金鑰時仍走 MyMemory，行為同前。

## 使用方式

1. A 側點「點一下說中文」，B 側點「Nhấn để nói」。按一下開始聽寫，再按一下可手動結束；停頓後也會自動結束。辨識中的文字會即時顯示。
2. 翻譯完成後，兩側顯示同一段對話：A 側看中文，B 側看越南文。若開啟自動播放，裝置會念出對方語言。每句旁的播放按鈕可再念一次；「複製」會把該句的中文與越南文一起複製到剪貼簿，可直接貼到 LINE 等通訊軟體。
3. 語音辨識不可用、權限被拒或辨識錯誤時，點該側鍵盤圖示，輸入文字並送出。翻譯失敗時保留原文，可按「重試」。
4. 工具列可開啟常用句、紀錄及設定。常用句需先指定由 A 或 B 發話，再點句子；可從對話加入常用句，也可刪除。設定可調整翻譯引擎、畫面模式、字體、兩種語言的聲音與語速、自動播放及選填電子郵件。
5. **朗讀聲音**：在「中文聲音／越南文聲音」各自選擇裝置提供的聲音，按旁邊的「試聽」聽範例句；選「自動」則由網頁依語言挑選。選擇會保存在目前瀏覽器。
6. **畫面模式**：「面對面」時越南文側倒轉 180 度，兩人隔著手機對坐；「並肩」時兩側同向，適合兩人坐在一起共用一副耳機（例如男生戴左耳、女生戴右耳）。共用耳機時兩人都會聽到所有語音，收音則走耳機麥克風（AirPods 可在 iPhone 設定 → 藍牙 → 麥克風 選擇固定用左或右耳）。

## 測試方式

1. 用電腦瀏覽器直接開啟 `index.html`，檢查開發者工具主控台是否有 JavaScript 錯誤。若瀏覽器沒有語音辨識，畫面應顯示提示，鍵盤輸入仍可用。
2. 網路可用時，由 A 側鍵盤輸入「你吃飽了嗎」，確認兩側顯示中文與越南文；由 B 側輸入「Em ăn cơm chưa」，確認兩側顯示越南文與中文。翻譯結果由 MyMemory 提供，請人工核對語意與字形。
3. 暫時斷網，再送出一句，確認錯誤提示、原文及「重試」出現，畫面不會一直停在翻譯中。恢復網路後再按重試。
4. 新增或刪除常用句、完成幾句對話後重新整理，檢查紀錄與常用句是否保留。清空紀錄時應先詢問確認。

## 需要 iPhone Safari 實機測試

- 使用 HTTPS 的 Safari **分頁**測試 `zh-TW` 與 `vi-VN` 聽寫、即時文字、停頓自動結束及再次點按手動結束。
- 測試麥克風權限拒絕、安靜無聲、8 秒保護計時器、網路中斷及錯誤提示的兩種語言。
- 測試譯文非同步返回後是否能自動播放、首次點按的語音解鎖、播放後再次聽寫是否能收音，以及兩種語言的聲音與語速。
- 確認畫面在不同 iPhone 尺寸、瀏海及底部橫條下完整可操作；確認 B 側從對面看時的文字與按鈕方向。
- 測試背景切換、Safari 重新載入及裝置上可用語音清單延後載入時的行為。

## 已知限制與資料處理

- 語音辨識、翻譯與部分語音播放依賴瀏覽器、裝置及網路；本版不支援離線翻譯。免費翻譯 API 有額度與單次文字長度限制。
- 越南文翻成中文時，MyMemory 可能回傳簡體字；本版不自動轉為繁體。譯文仍需由使用者核對，尤其是人名、地名與重要內容。
- 對話、常用句與設定存在目前瀏覽器的 `localStorage`；清除網站資料或使用無痕模式可能使它們消失。翻譯文字會送往 MyMemory；若設定電子郵件，翻譯請求也會附上該地址。
- 可用的中文或越南文聲音由裝置決定；缺少對應聲音時，瀏覽器會依語言代碼自行選擇，發音可能不同。iPhone 的首次播放、播放後收音及語音辨識支援情況都需要實機確認。
- 網頁無法自行產生男聲或女聲；可選的聲音由裝置提供。iPhone 可到「設定 → 輔助使用 → 朗讀內容 → 聲音」下載更多聲音，然後重新整理網頁。
- **藍牙耳機**：一支 iPhone 同時只能用一副藍牙耳機的麥克風；兩人各戴一副且各自收音做不到。共用一副（一人一耳）可行，但網頁無法把中文與越南文分別送到左右耳，兩人都會聽到全部語音。
- **iPhone 靜音開關會讓語音播放無聲**（實機確認，2026-11-16）：iOS 把 Safari 的語音朗讀歸為提示音，側邊開關切到靜音時不會出聲，音樂與影片則不受影響。網頁無法繞過此限制；使用前請關閉靜音並調高音量。設定面板與播放錯誤訊息都已加上提示。
